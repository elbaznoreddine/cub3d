# 🕹️ cub3d

A 3D maze runner built in C, inspired by the classic raycasting style of old-school first-person shooters.

This project transforms a flat map into a dynamic world using raycasting, movement, and perspective. It is a deep dive into geometry, rendering, and real-time simulation.

## 🎮 Features

- 3D maze rendering
- Keyboard-based movement
- Map parsing and validation
- Real-time perspective projection

## 🛠️ Build and launch

```bash
make
./cub3d maps/map.cub
```

## 💡 What this project teaches

- Math behind perspective rendering
- Event-driven game loops
- C memory and performance awareness
- Building a playable prototype from scratch

> Every wall is a math problem, and every angle is a clue.
